## Objetivo:

Este projeto tem a missão de ser o facilitador na tomada de decisão para reduzir o aquecimento global, contendo visualizações e projeções da situação climática.

## Estrutura Do Projeto:

***data/datasets:*** Recebe os arquivos via API

**docs:** Hospeda os arquivos *Data Sumary Report,* *Project Charter*, *TDSP* e respostas dos questionários dos *TPs*

**src/app.py:** Compoê as visualizações

***src/data.py:*** Coleta os arquivos CSVs e transforma em dataframe

***util/image:*** Hospeta imagens
